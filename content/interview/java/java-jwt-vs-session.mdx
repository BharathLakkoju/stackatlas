Compare session cookies and JWT for authentication.

## Model answer

Session: server stores session id cookie; easy revoke by deleting server state; needs sticky sessions or shared store at scale. JWT: signed claims client holds; verify with secret/public key without DB hit—good horizontal scale. Revocation hard—short TTL + refresh token rotation, denylist for compromise. XSS steals bearer in localStorage—prefer HttpOnly refresh cookie + memory access token. JWT size adds headers; do not stuff large claims. Rotate signing keys via JWKS.
