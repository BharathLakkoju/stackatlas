Why doesn't @Transactional work on a private method called from same class?

## Model answer

Spring applies transactions via JDK/CGLIB proxy around bean. External calls hit proxy; internal this.method() calls target object directly—no transaction aspect. Fix: move transactional method to another bean, inject self interface, or use AspectJ weaving. private/final also non-proxied for CGLIB limits. Propagation REQUIRED joins existing tx; REQUIRES_NEW suspends. rollbackFor includes checked exceptions you list. readOnly hints Hibernate. Enable @EnableTransactionManagement.


## Follow-ups

### Propagation REQUIRED?

REQUIRED joins caller transaction; REQUIRES_NEW always new transaction.

### Rollback rules?

Default rolls back on RuntimeException only—specify rollbackFor for checked.
