How do you deploy to AWS from GitHub Actions without long-lived keys?

## Model answer

Configure IAM OIDC identity provider for token.actions.githubusercontent.com. IAM role trust policy allows sts:AssumeRoleWithWebIdentity with condition on sub repo:org/repo:ref:refs/heads/main and aud sts.amazonaws.com. Workflow permissions id-token: write, uses aws-actions/configure-aws-credentials with role-to-assume. Short-lived creds per job—no keys in secrets. Scope roles per environment (staging/prod) with branch/environment conditions. Audit CloudTrail AssumeRole events.


## Follow-ups

### Trust policy conditions?

Condition StringEquals token.actions.githubusercontent.com:sub to exact repo/branch.

### Environment protection?

GitHub environments require reviewers before prod role assumption.
