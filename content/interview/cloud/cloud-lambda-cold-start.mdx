What causes Lambda cold starts and how do you reduce them?

## Model answer

Cold path: download image, start runtime, run static init, optional VPC ENI attach—adds seconds worst case. Mitigate: smaller deployment packages, lazy imports, arm64 Graviton often faster/cheaper, avoid unnecessary VPC or use VPC endpoints + newer hyperplane ENI faster attach. Provisioned concurrency keeps instances warm—cost tradeoff. SnapStart for Java restores from snapshot. Keep handler outside global heavy work—init once at module scope carefully. API Gateway timeouts must exceed worst cold+p95 processing.


## Follow-ups

### SnapStart?

SnapStart snapshots initialized Java runtime after first invoke.

### Arm vs x86?

Graviton arm64 can reduce cost and sometimes init time vs x86.
