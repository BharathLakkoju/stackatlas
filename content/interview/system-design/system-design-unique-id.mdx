High-rate unique sortable IDs across machines.

## Model answer

64-bit: timestamp | machine_id | sequence per ms. Assign machine ids; on same ms increment sequence, wait next ms on overflow.

Monitor clock skew; refuse if clock moves backward.

UUID v4 random opaque; snowflake better DB index locality.


## Follow-ups

### UUID vs snowflake?

UUID not time-sorted; snowflake roughly increasing.

### Global monotonic?

Strict global order needs single sequencer; snowflake is approximate sort.
