Typeahead suggestions for search box.

## Model answer

Precompute top-k per prefix from logs; trie or sorted prefix table in memory.

Client debounce 150-300ms. CDN cache hot prefixes.

Pipeline aggregates popularity with decay; filter banned terms.


## Follow-ups

### Personalization?

Blend user history with capped weight.

### Typo tolerance?

Fuzzy match on top candidates or spell-correct service.
