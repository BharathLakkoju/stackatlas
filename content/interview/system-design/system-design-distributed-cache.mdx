Shared cache for stateless app tier.

## Model answer

Cache-aside: read Redis; miss load DB set TTL. Write DB then invalidate key.

Consistent hash shards; optional replica per shard.

Single-flight lock on miss prevents stampede.


## Follow-ups

### Hot keys?

Replicate hot key or local micro-cache.

### Invalidation?

Delete-on-write; versioned keys for coherence.
