Design real-time chat with 1:1 and groups.

## Model answer

Clients WebSocket to connection tier; persist messages with server ids; fan-out to online users via connection registry.

Ordering per room by server sequence. Client_msg_id dedupes retries.

Offline: sync on reconnect from last acked seq. Push for mobile offline.


## Follow-ups

### Large groups?

Cap group size; broadcast channels use pub/sub backbone.

### End-to-end encryption?

E2EE limits search/moderation; keys stay on clients.
