Distributed rate limiter per API key.

## Model answer

Token bucket allows burst with average rate. Redis Lua atomically refills and decrements per key.

Enforce at API gateway; 429 on deny. Regional Redis or per-region limits for multi-region.

Fail closed for payments; configurable per tier.


## Follow-ups

### Sliding vs token bucket?

Sliding window more precise; token bucket smoother bursts.

### Per-tenant quotas?

Quota profiles in config service keyed by tenant.
