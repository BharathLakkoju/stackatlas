Large-scale crawler for search index.

## Model answer

Frontier per host rate limits; fetchers pull tasks; parser extracts links; bloom dedup URLs.

Respect robots.txt; store HTML in object store; metadata DB tracks status.

Optional headless queue for JS sites only.


## Follow-ups

### JS rendering?

Headless farm expensive; fast path static HTML.

### Near-duplicates?

Simhash for near-duplicate detection.
