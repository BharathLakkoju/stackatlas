Why add keyword search to vector RAG?

## Model answer

Embeddings miss exact token matches—IDs, SKUs, acronyms, rare names. BM25 excels lexical overlap. Hybrid runs both retrievers, merges with reciprocal rank fusion or weighted score. Tune alpha on dev queries. Store sparse vectors in same engine (OpenSearch, pgvector+tsvector) when possible. Log which leg hit for debugging. Hybrid especially helps enterprise glossaries and error codes.
