How do you prevent runaway agent tool loops?

## Model answer

Set max_steps and token budget. After each model turn, parse tool calls, validate JSON schema, execute with timeouts, append observations. Stop on finish tool or no tool requested. Reject recursive call patterns in policy. Log full trace for replay. Parallelize independent tools when safe. Human-in-the-loop gate for destructive actions (delete, pay). Use graph state machines (LangGraph) for explicit transitions vs free-form ReAct only.


## Follow-ups

### Parallel tools?

Batch read-only tools concurrently; serialize writes.

### Human approval?

Approval node blocks until human confirms high-risk tool.
