In `@a @b def f`, which runs first?

## Model answer

Equivalent to f = a(b(f))—b wraps f first, then a wraps the result. Order matters: @auth above @log means outer auth sees logged inner call. Use functools.wraps to preserve __name__ and __doc__. Parametrized decorators are three levels: decorator factory returns decorator returns wrapper. classmethod/staticmethod are descriptor decorators changing binding.

### Parametrized decorators?

classmethod binds cls; placed correctly above user decorators depending on desired binding.
