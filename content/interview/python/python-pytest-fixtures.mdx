Explain fixture scope and yield teardown.

## Model answer

Fixtures inject dependencies into tests by name. scope=function default new each test; module/session share expensive setup. yield provides teardown after tests run—even on failure. conftest.py fixtures discover hierarchically. autouse applies without parameter for DB rollback blanket. Use factory fixtures returning callable for parameterized data. Avoid global mutable singletons tests share accidentally.
