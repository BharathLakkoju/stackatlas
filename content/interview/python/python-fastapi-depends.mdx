How does FastAPI Depends work for DB sessions?

## Model answer

Depends registers callable resolved before route runs. yield fixtures open session, yield to handler, close in finally—request-scoped lifecycle. Depends can nest: route depends on service depends on db. use_cache=True singletons settings. Override dependencies in tests via app.dependency_overrides. Security dependencies combine OAuth scopes with Depends. Keep callables sync unless truly async driver—async def route with sync session OK if non-blocking.
