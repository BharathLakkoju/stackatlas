Why does `for (var i=0;i<5;i++) setTimeout(()=>console.log(i),100)` print five 5s?

## Model answer

All timeouts share one function-scoped i. When they fire, the loop finished with i=5. Use let for per-iteration bindings, an IIFE capturing i, or pass i as setTimeout's third argument. Closures retain outer bindings while inner functions live—avoid capturing large objects in long-lived listeners. ES modules close over private top-level state similarly to the module pattern.


## Follow-ups

### Memory implications?

Remove listeners and drop references so closures become collectable.

### Module pattern?

IIFE returned API object exposes methods while hiding private vars.
