Explain debounce and throttle with use cases.

## Model answer

Debounce: run after events pause (search API 300ms after last key). Throttle: at most once per window while events fire (scroll position). Leading vs trailing variants. lodash debounce cancel/flush. React: stable callbacks + refs for latest args. rAF throttles visual updates to display refresh.


## Follow-ups

### Leading vs trailing edge?

Leading fires immediately then waits; trailing waits for pause.

### requestAnimationFrame throttle?

rAF ~60fps paint sync; separate throttle for network side effects.
