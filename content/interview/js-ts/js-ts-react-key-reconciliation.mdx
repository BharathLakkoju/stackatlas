Why does React need keys, and why is index often wrong?

## Model answer

Keys identify which logical row survived reorder. Index keys tie identity to position—sort/insert remaps state to wrong rows and wastes DOM work. Keys are sibling-unique hints to reconciler, not props. Stable ids from data beat index. Random per render forces remount every pass. React.memo still needs list keys upstream.


## Follow-ups

### Key=random?

Random keys remount children constantly.

### Fragment keys?

Use Fragment key when returning keyed adjacent lists.
