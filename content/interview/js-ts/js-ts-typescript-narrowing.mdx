How does TypeScript narrow types in conditionals?

## Model answer

typeof, truthiness, and early return refine unions. Discriminated unions narrow on kind field. in operator checks fields. User-defined guards return p is T. asserts functions throw to narrow after call. Prefer runtime validation (Zod) at boundaries then narrow. never in default proves exhaustiveness.
