How do Promise callbacks interact with the event loop compared to setTimeout?

## Model answer

Executor runs synchronously; then/catch schedule microtasks after current stack. All microtasks run before next macrotask like setTimeout. Nested promise chains can starve timers if abused. Rejections must be caught or trigger unhandledrejection. async/await is sugar—continuations are microtasks. Node's process.nextTick runs before promise microtasks.


## Follow-ups

### Unhandled rejection?

Always end server chains with catch and log unhandledRejection.

### Promise.all vs allSettled?

all rejects on first failure; allSettled waits for every promise.
