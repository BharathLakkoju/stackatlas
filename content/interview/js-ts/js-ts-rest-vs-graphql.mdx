Compare REST and GraphQL for a product API.

## Model answer

REST: resource URLs, CDN-friendly GET caching, simple ops. GraphQL: one POST, client picks fields—less round trip, more server complexity, N+1 without DataLoader, query cost limits required. REST for cacheable CRUD and uploads; GraphQL for varied clients and evolving schemas. Both need auth, rate limits, observability. gRPC internal; browser needs gateway.


## Follow-ups

### GraphQL caching?

Persisted queries and GET hashes enable CDN for allowlisted operations.

### Versioning?

REST /v2 paths; GraphQL deprecate fields with schema tracking.
