With numCourses and prerequisites [a,b] meaning b before a, can you finish all courses?

## Model answer

Build directed edges b→a. Cycle ⇒ impossible.

DFS three-color: visiting node on active path ⇒ cycle. Or Kahn BFS: enqueue in-degree 0, decrement neighbors; process all nodes if acyclic.

Both O(V+E). Kahn outputs topological order when acyclic.

**Complexity:** Time O(V+E), space O(V+E).

## Follow-ups

### Return valid order?

Kahn list or reverse DFS post-order gives valid ordering.

### Parallel prerequisites?

Multiple edges increase in-degree only; logic unchanged.
