Find the length of the longest substring of s without repeating characters.

## Model answer

Keep window [lo, hi] and map char -> last index. For each hi, if s[hi] was seen with index >= lo, set lo = last[s[hi]] + 1. Update last[s[hi]] = hi and best = max(best, hi - lo + 1).

Invariant: substring s[lo..hi] has all unique chars. Each index moves forward at most once → O(n).

Distinct from 'at most k distinct', which tracks frequencies and shrinks while distinct > k.

**Complexity:** Time O(n), space O(min(n, alphabet)).

## Follow-ups

### At most k distinct?

Use frequency map; expand hi, shrink lo while distinct > k.

### Return the substring itself?

Track bestLo/bestHi when updating best; return slice at end.
