Fewest coins to make amount, or -1 if impossible.

## Model answer

dp[a] = min coins for amount a. dp[0]=0, others ∞. For each a and coin c: dp[a] = min(dp[a], dp[a-c]+1) when a>=c.

Answer dp[amount] or -1. O(amount * |coins|) time.

Greedy on arbitrary coins can be wrong; canonical systems like US coins are special cases only.

**Complexity:** Time O(amount × |coins|), space O(amount).

## Follow-ups

### Count ways?

Ways to make change: sum dp[a-c] with dp[0]=1 (combinations order).

### When is greedy safe?

Counterexample [1,3,4] amount 6: greedy uses 3 coins, optimal 2.
