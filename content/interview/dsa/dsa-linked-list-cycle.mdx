Detect if a linked list has a cycle.

## Model answer

Slow moves 1, fast moves 2. If fast hits null, no cycle. If slow==fast, cycle exists.

O(n) time, O(1) space vs hash set O(n) space.

To find entry: after meet, reset one pointer to head, advance both one step until equal—entrance node.

**Complexity:** Time O(n), space O(1).

## Follow-ups

### Cycle length?

Walk one pointer counting steps until remeet for length.

### Cycle start?

Head + one-step until meeting gives start node.
