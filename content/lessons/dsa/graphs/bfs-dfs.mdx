## Why this matters

Social graphs, grids, dependencies, and islands in a matrix are all **graphs**. Interviews rarely hand you a `Graph` class — you build adjacency from edges or neighbors and choose BFS or DFS. Wrong choice costs clarity: BFS for **shortest steps** in unweighted graphs; DFS for **cycles**, **connected components**, and deep path exploration.

Both are `O(V + E)` when you visit each vertex and edge once. Space is `O(V)` for the visited set and queue or recursion stack.

## Mental model

**BFS** is ripples in a pond: enqueue the start, dequeue the front, push unseen neighbors. The first time you reach a node is along a shortest path in an unweighted graph.

**DFS** is explore one hallway to the end, backtrack, try the next branch. Use an explicit stack or recursion; mark visited when you **discover** a node, not when you finish backtracking (for standard coloring).

Grids: treat each cell as a vertex; edges to four or eight neighbors. Use a `Set` or `visited` matrix with a stable key like `row * cols + col`.

## Code

```ts
type Adjacency = Map<number, number[]>;

function buildUndirectedGraph(n: number, edges: [number, number][]): Adjacency {
  const adj = new Map<number, number[]>();
  for (let i = 0; i < n; i += 1) {
    adj.set(i, []);
  }
  for (const [u, v] of edges) {
    adj.get(u)?.push(v);
    adj.get(v)?.push(u);
  }
  return adj;
}

function bfsShortestDistance(adj: Adjacency, start: number): Map<number, number> {
  const dist = new Map<number, number>();
  const queue: number[] = [start];
  dist.set(start, 0);
  let head = 0;
  while (head < queue.length) {
    const u = queue[head];
    head += 1;
    const du = dist.get(u) ?? 0;
    for (const v of adj.get(u) ?? []) {
      if (!dist.has(v)) {
        dist.set(v, du + 1);
        queue.push(v);
      }
    }
  }
  return dist;
}

function dfsHasCycleDirected(adj: Adjacency, n: number): boolean {
  const state = new Array<number>(n).fill(0);
  function visit(u: number): boolean {
    state[u] = 1;
    for (const v of adj.get(u) ?? []) {
      if (state[v] === 1) {
        return true;
      }
      if (state[v] === 0 && visit(v)) {
        return true;
      }
    }
    state[u] = 2;
    return false;
  }
  for (let u = 0; u < n; u += 1) {
    if (state[u] === 0 && visit(u)) {
      return true;
    }
  }
  return false;
}

function countIslands(grid: string[][]): number {
  if (grid.length === 0) {
    return 0;
  }
  const rows = grid.length;
  const cols = grid[0].length;
  let count = 0;
  function dfs(r: number, c: number): void {
    if (r < 0 || c < 0 || r >= rows || c >= cols || grid[r][c] === "0") {
      return;
    }
    grid[r][c] = "0";
    dfs(r + 1, c);
    dfs(r - 1, c);
    dfs(r, c + 1);
    dfs(r, c - 1);
  }
  for (let r = 0; r < rows; r += 1) {
    for (let c = 0; c < cols; c += 1) {
      if (grid[r][c] === "1") {
        count += 1;
        dfs(r, c);
      }
    }
  }
  return count;
}
```

## Common mistakes

- Using BFS on weighted graphs without noticing — you need Dijkstra (non-negative weights) or Bellman-Ford.
- DFS cycle check on **undirected** graphs treating the parent edge as a back-edge incorrectly.
- Forgetting to mark visited **before** enqueue/push, causing duplicate queue work.
- Grid DFS blowing the stack on huge inputs — switch to BFS or iterative DFS with an explicit stack.

## Interview angles

- “Word ladder” — BFS on implicit graph of one-letter edits.
- “Course schedule” — cycle detection in directed graph (Kahn topological sort or DFS colors).
- “Clone graph” — DFS/BFS with a map from old node to clone ([hashing](/learn/dsa/patterns/hashing) for the visited map).

When paths have overlapping subproblems on **structures without explicit graphs**, pair traversals with [1D dynamic programming](/learn/dsa/dynamic-programming/dp-1d).
