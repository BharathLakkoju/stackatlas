## Why this matters

FastAPI route handlers and dependencies are saturated with decorators: `@app.get`, `@lru_cache`, custom permission checks. If decorators feel like magic, you cannot debug wrapper order, lost metadata, or async vs sync mistakes.

They are also the bridge from [GIL](/learn/python/internals/gil)-level "how calls run" to framework injection patterns in dependency injection.

## Mental model

`@decorator` above `def f` means `f = decorator(f)`. The decorator is a callable that receives a function and returns a **replacement** callable (often a wrapper).

**Stacking**: bottom decorator runs first—`@a` then `@b` becomes `a(b(f))`.

**Preserving metadata**: use `functools.wraps(inner)` so `__name__` and docstrings survive.

**Parameterized decorators**: outer function returns the actual decorator: `@retry(times=3)` is `retry(times=3)(func)`.

Async wrappers must `await` the inner coroutine function.

## Code

```python
import functools
import time
from collections.abc import Callable
from typing import ParamSpec, TypeVar

P = ParamSpec("P")
R = TypeVar("R")


def timed[**P, R](func: Callable[P, R]) -> Callable[P, R]:
    @functools.wraps(func)
    def wrapper(*args: P.args, **kwargs: P.kwargs) -> R:
        start = time.perf_counter()
        try:
            return func(*args, **kwargs)
        finally:
            elapsed = time.perf_counter() - start
            print(f"{func.__name__} took {elapsed:.4f}s")

    return wrapper


def retry(times: int) -> Callable[[Callable[P, R]], Callable[P, R]]:
    def decorator(func: Callable[P, R]) -> Callable[P, R]:
        @functools.wraps(func)
        def wrapper(*args: P.args, **kwargs: P.kwargs) -> R:
            last_error: BaseException | None = None
            for attempt in range(times):
                try:
                    return func(*args, **kwargs)
                except BaseException as exc:
                    last_error = exc
                    if attempt + 1 == times:
                        raise
            assert last_error is not None
            raise last_error

        return wrapper

    return decorator


@timed
@retry(times=3)
def load_config(path: str) -> dict[str, str]:
    with open(path, encoding="utf-8") as handle:
        line = handle.readline().strip()
    return {"first_line": line}


def main() -> None:
    print(load_config(__file__))


if __name__ == "__main__":
    main()
```

`retry` is parameterized; `timed` is a simple wrapper. `wraps` keeps `load_config` identifiable in stack traces.

## Common mistakes

- Forgetting `wraps`, breaking observability and OpenAPI tool introspection.
- Decorating async functions with sync wrappers that never await.
- Returning the wrong object from a decorator factory (missing inner `return wrapper`).
- Assuming decorator order does not matter when auth and caching stack.
